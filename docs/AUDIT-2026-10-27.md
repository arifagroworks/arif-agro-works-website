4. Food preview warned about imported overlapping periods but still displayed double-counted shares. It now blocks calculation when the selected report contains overlapping worker periods, including overlaps between company-paid and salary-deducted periods. No records are deleted or rewritten.
5. The APK workflow had no test prerequisite. It now runs isolated browser/calculation regressions on PRs, main pushes and manual runs. APK build requires successful tests, and output verification checks package, launcher activity and bundled logo.
